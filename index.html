Architecture

Design stack for the live build

  • Agents: OpenAI Agents SDK (Python); LangGraph if the workflow grows
  • Memory & audit: Supabase / Postgres, 18 tables, time-stamped evidence
  • Source files: Google Drive, read-only, treated as untrusted data
  • Publishing & analytics: social API adapter with idempotency keys and signed webhooks
  • Scheduling: cron triggers plus a persistent worker with retries
